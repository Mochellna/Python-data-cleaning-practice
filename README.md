# 英国电商销售数据清洗 / UK E-commerce Sales Data Cleaning

## 项目概览 / Project Overview
根据市场销售数据，挖掘畅销产品，以便制定更有效的市场策略来提升营收。  
本项目旨在练习评估数据干净和整洁度，并基于评估结果对数据进行清洗，为下一步分析准备可用数据。

## 背景 / Background
原始数据集记录了一家英国在线零售公司在2010年12月1日至2011年12月9日期间的所有交易情况，涵盖公司在全球不同国家和地区的业务数据。该公司主要销售各类礼品，包括生日礼品、结婚纪念品、圣诞礼品等，客户群体包括个人消费者和批发商，其中批发商占据较大比例。

## 数据概览 / Data Overview
- **时间范围**：2010年12月1日 – 2011年12月9日  
- **客户类型**：个人消费者与批发商  
- **产品类别**：生日礼品、结婚纪念品、圣诞礼品等  
- **数据问题**：缺失值、重复记录、取消订单、负数数量等  

### 数据字段说明 / Data Description
| 列名 | 含义 |
|------|------|
| InvoiceNo | 发票号码，6位数。以“C”开头表示交易被取消。 |
| StockCode | 产品代码，5位数，用于唯一标识产品。 |
| Description | 产品名称。 |
| Quantity | 产品数量。 |
| InvoiceDate | 发票日期和时间。 |
| UnitPrice | 单价，单位为英镑（£）。 |
| CustomerID | 客户编号，5位数，用于唯一标识客户。 |
| Country | 客户所在国家名称。 |

## 分析流程 / Analysis Process
本项目主要进行数据清洗与评估，流程包括：
1. **数据检查**：评估缺失值、重复值、异常数量和负数交易。  
2. **数据清洗**：删除取消订单和重复记录，修正负数或异常数量和单价。  
3. **字段处理**：统一日期格式，确保字符串字段一致性。  
4. **数据可视化（探索性分析）**：绘制销售量、销售额分布图，初步识别畅销产品和主要客户群体。
